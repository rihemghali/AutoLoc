# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet

Développer une application Java/Spring Boot permettant de gérer la location de véhicules
à travers plusieurs agences : gestion des véhicules, des réservations, des clients et
des utilisateurs internes.

## Acteurs identifiés

- **Client** : consulte les véhicules disponibles et effectue des réservations.
- **Agent d'agence** : gère les réservations et les véhicules au quotidien dans son agence.
- **Responsable d'agence** : supervise l'activité de son agence et son équipe d'agents.
- **Administrateur** : gère l'ensemble du système, les agences et les comptes utilisateurs.

## Stack technique

Java 17, Spring Boot, Spring Data JPA, MySQL, Maven, Lombok.
